# LoM Launcher v0.1.8 (DEV)

Предварительный релиз канала DEV. Основной канал по-прежнему остаётся на v0.1.7.

## Что исправлено

- Последний пункт настроек и заголовок его секции отображались как одна буква «О» вместо названия. Теперь это «Обновление»; блок со сведениями о лаунчере и отладочной информацией получил отдельную подпись «О лаунчере».

## Проверка канала

- В настройках обновления включите тумблер «Канал обновлений DEV» — лаунчер увидит v0.1.8.
- С выключенным тумблером основной канал продолжает видеть v0.1.7.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-Setup-0.1.8-x64.exe`;
- `LoM-Launcher-Setup-0.1.8-x64.exe.sha256`;
- `LoM-Launcher-v0.1.8-windows-x64.zip`;
- `LoM-Launcher-v0.1.8-windows-x64.zip.sha256`;
- `app-0.1.8-win.asar`;
- `app-0.1.8-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
