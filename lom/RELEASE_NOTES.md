# LoM Launcher v0.1.4

Мостовой релиз для перехода на встроенное обновление самого LoM Launcher.

## Что изменилось

- Раздел «Настройки → Обновление» теперь проверяет релизы `nondename/LoM-Launcher-XMCL`, а не инфраструктуру оригинального XMCL.
- Для совместимых обновлений лаунчер скачивает versioned `app.asar` прямо из LoM GitHub Releases.
- Перед установкой `app.asar` обязательно проверяется SHA-256; повреждённый или подменённый файл не применяется.
- После загрузки обновление устанавливается через существующий механизм замены `app.asar` и перезапуска лаунчера.
- Если релиз затрагивает Electron/native/упаковку и не может безопасно обновляться одним `app.asar`, используется полный ZIP как ручной fallback.
- ASAR-обновление публикуется только для релизов, явно помеченных `"inAppUpdate": true`.
- Ссылки окна обновления ведут на репозиторий и Releases проекта LoM.
- В релиз также входят актуальные изменения локальных скинов/плащей, уже слитые в `master` после v0.1.3.

## Важно для v0.1.3

Версия v0.1.3 ещё не содержит нового LoM updater, поэтому переход **v0.1.3 → v0.1.4 нужно выполнить вручную один последний раз**.

Начиная с v0.1.4, следующие ASAR-совместимые версии можно будет скачать и установить через настройки лаунчера без ручной замены ZIP.

## Проверено

- Feature build `LoM Windows Test Build #64` успешно прошёл полностью.
- Production Windows build успешно собрал `LoM Launcher.exe`.
- Проверки LoM distribution adapter и живых загрузок сборки прошли успешно.

## Загрузка

Для Windows x64 используйте `LoM-Launcher-v0.1.4-windows-x64.zip`, распакуйте архив и запускайте `LoM Launcher.exe`.

Рядом с полным ZIP публикуется SHA-256. Для этого релиза также публикуются `app-0.1.4-win.asar` и `app-0.1.4-win.asar.sha256` для нового механизма обновления.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
