# LoM Launcher v1.8.12

Добавлен третий управляемый инстанс **NeVanilla**.

- NeVanilla создаётся автоматически отдельно от Legends of Medieval и Lite.
- Minecraft 1.20.1 / Forge 47.4.22 / Java 17.
- Отдельный managed profile ID: `nevanilla-lomine`.
- Манифест: `https://raw.githubusercontent.com/nondename/NeVanilla-LoMine/main/distribution.json`.
- Существующие инстансы и пользовательские конфигурации не перезаписываются.
- Обновление лаунчера распространяется через встроенный механизм in-app update; переустановка не требуется.
