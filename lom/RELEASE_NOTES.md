# LoM Launcher v0.1.6

Хотфикс встроенного обновления после проверки перехода с v0.1.4 на v0.1.5. Функции локального гардероба плащей из v0.1.5 сохранены.

## Что исправлено

- Исправлен сценарий, когда лаунчер видит новую версию, но кнопка «Скачать и установить» не приводит к загрузке.
- Для проверки ASAR теперь в первую очередь используется SHA-256 `digest`, который GitHub уже возвращает вместе с release asset.
- Отдельный `.sha256` сохранён как fallback для релизов без `digest`.
- Добавлен второй маршрут загрузки через GitHub asset API, если обычный `browser_download_url` не срабатывает.
- Ошибки скачивания и установки теперь показываются прямо в окне обновления вместо визуального «ничего не произошло».

## Плащи

В релиз входит локальный гардероб плащей из v0.1.5:

- добавление и хранение локальных PNG-плащей;
- выбор активного плаща для профиля;
- экспорт в `.lom/player/cape.png` перед запуском;
- запись `capeSha256` в `.lom/player/profile.json` для LoM Skin Loader;
- очистка runtime-плаща при его отключении.

## Важно для пользователей v0.1.4

В v0.1.4 сломан именно этап скачивания встроенного обновления. Поэтому один переход на v0.1.6 может потребовать ручной установки полного ZIP. После запуска v0.1.6 следующие ASAR-обновления должны снова устанавливаться из самого лаунчера.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-v0.1.6-windows-x64.zip`;
- `LoM-Launcher-v0.1.6-windows-x64.zip.sha256`;
- `app-0.1.6-win.asar`;
- `app-0.1.6-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
