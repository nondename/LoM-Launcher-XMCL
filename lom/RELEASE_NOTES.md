# LoM Launcher v0.1.3

Стабильный релиз цепочки установки Legends of Medieval.

## Что изменилось

- Чистая установка теперь идёт одним непрерывным сценарием: после установки или восстановления Minecraft 1.20.1 и Forge 47.4.22 лаунчер автоматически запускает установку файлов LoM.
- Убран второй ручной клик «Установить» между runtime-этапом и установкой сборки.
- `options.txt` используется только как стартовый seed: при первой установке задаётся `lang:ru_ru`, после чего обновлятор сохраняет пользовательские настройки Minecraft.
- `options.txt` защищён от удаления через `distribution.json`.
- Сохранены исправления v0.1.2 для обновления сборки, отмены загрузки, повторной проверки и целостности файлов.

## Проверено

- Изменения из тестовой сборки `lom-windows-b53` слиты в `master`.
- Windows test build на `master` после merge PR #9 успешно прошёл CI.
- Цепочка Minecraft/Forge → LoM updater выполняется автоматически.

## Загрузка

Для Windows x64 используйте `LoM-Launcher-v0.1.3-windows-x64.zip`, распакуйте архив и запускайте `LoM Launcher.exe`.

SHA-256 публикуется отдельным файлом рядом с архивом.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
