# LoM Launcher v0.1

Первый публичный релиз LoM Launcher для Legends of Medieval.

## Что входит

- LoM-брендинг и отдельная Windows-сборка `LoM Launcher.exe`.
- Zero-config создание профиля Legends of Medieval.
- Встроенный LoM updater для синхронизации файлов сборки по manifest.
- Автоматическая подготовка Minecraft 1.20.1 + Forge 47.4.22 перед установкой LoM-файлов.
- Исправлена отмена нативной загрузки Minecraft/Forge/assets: кнопка `Отменить` теперь реально прерывает связанные загрузки.
- Состояние `Cancelled` сделано терминальным, поэтому позднее завершение асинхронной операции не превращает отменённую задачу обратно в `Succeed`.
- Authlib Injector по умолчанию отключён для LoM-профиля.

## Загрузка

Для Windows x64 используйте `LoM-Launcher-v0.1.0-windows-x64.zip`, распакуйте архив и запускайте `LoM Launcher.exe`.

SHA-256 опубликован отдельным файлом рядом с архивом.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
