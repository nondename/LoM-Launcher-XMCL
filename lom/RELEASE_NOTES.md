# LoM Launcher v0.1.1

Стабилизационный релиз установки Legends of Medieval.

## Что изменилось

- Лаунчер устанавливает реальную сборку Legends of Medieval из актуального `distribution.json`.
- LoM-загрузка интегрирована в штатный менеджер задач XMCL: отображаются текущий файл, URL, прогресс и скорость загрузки.
- LoM-трафик теперь отображается в разделе сетевых подключений XMCL.
- Добавлены повторные попытки для временных сетевых ошибок.
- При отмене или сбое уже проверенные `.lom-update` файлы сохраняются и повторно используются при следующем запуске установки.
- Проверка целостности учитывает безопасные преобразования окончаний строк для текстовых конфигов, сохраняя строгую проверку бинарных файлов.
- Исправлены проблемы с URL-кодированными именами файлов и прямыми загрузками модов/ресурспаков из GitHub.
- Производственный manifest сборки синхронизируется с реально опубликованными Git-файлами и проверяется на отсутствующие файлы, размеры, MD5, URL и дубликаты.
- Исправлена загрузка полного набора конфигов, модов, ресурспаков и остальных файлов сборки без устаревших 404-записей.
- Сохранена нативная отмена загрузок Minecraft/Forge/assets.

## Проверено

- Чистая установка Minecraft 1.20.1 + Forge 47.4.22.
- Полная загрузка Legends of Medieval.
- Запуск установленной сборки.
- Русская локализация интерфейса и сборки.

## Загрузка

Для Windows x64 используйте `LoM-Launcher-v0.1.1-windows-x64.zip`, распакуйте архив и запускайте `LoM Launcher.exe`.

SHA-256 опубликован отдельным файлом рядом с архивом.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
