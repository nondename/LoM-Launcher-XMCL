# LoM Launcher v1.8.3 (DEV)

Предварительный релиз канала DEV. Основной канал остаётся на v1.8.2.

## Что изменено

- Убрана надпись с ником над 3D-моделью скина в боковой панели — теперь там только модель.

## Проверка обновления

Этот релиз нужен, чтобы проверить встроенное обновление end-to-end:

1. Поставьте `LoM-Launcher-Setup-1.8.2-x64.exe` (или обновитесь до 1.8.2).
2. В настройках обновления включите тумблер «Канал обновлений DEV».
3. Нажмите «Скачать и установить» — лаунчер должен скачать v1.8.3 и перезапуститься.

С выключенным тумблером основной канал продолжает видеть v1.8.2.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-Setup-1.8.3-x64.exe`;
- `LoM-Launcher-Setup-1.8.3-x64.exe.sha256`;
- `LoM-Launcher-v1.8.3-windows-x64.zip`;
- `LoM-Launcher-v1.8.3-windows-x64.zip.sha256`;
- `app-1.8.3-win.asar`;
- `app-1.8.3-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
