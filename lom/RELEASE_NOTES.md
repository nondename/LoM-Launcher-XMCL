# LoM Launcher v0.1.2

Стабильный релиз обновлений Legends of Medieval поверх уже установленной сборки.

## Что изменилось

- Исправлено определение обновлений сборки: лаунчер теперь использует верхнеуровневый `distribution.version`, поэтому изменения модов и других файлов сборки корректно обнаруживаются даже без изменения версии сервера.
- Добавлена поддержка `delete` из `distribution.json`: устаревшие файлы теперь удаляются из уже существующих установок.
- Проверен первый реальный инкрементальный апдейт LoM на обновлении Antique Atlas.
- Новый исправленный `Antique Atlas-1.20.1-8.0.1-Forge.jar` корректно скачивается напрямую из GitHub и проходит проверку MD5.
- Старый отдельный `Antique Atlas 1.20.1.jar` (Recipe Fix) автоматически удаляется при обновлении.
- В CI добавлена постоянная проверка живого `distribution.json`, прямой загрузки Antique Atlas, его MD5 и списка удаляемых файлов.
- Сохранены предыдущие исправления загрузчика: отмена, повторные попытки, повторное использование проверенных `.lom-update` файлов, URL-декодирование имён и проверка целостности.

## Проверено

- `distribution.json` версии `1.0.1` успешно распознаётся как обновление сборки.
- Живой Antique Atlas скачивается с HTTP 200, размером 1 498 804 байта и MD5 `5ba145dac6c2df699d8002236b8fb4be`.
- Устаревший Recipe Fix отсутствует в списке устанавливаемых файлов и присутствует в `delete`.
- Unit-тесты адаптера LoM проходят.
- Полная Windows x64 сборка `LoM Launcher.exe` проходит CI.

## Загрузка

Для Windows x64 используйте `LoM-Launcher-v0.1.2-windows-x64.zip`, распакуйте архив и запускайте `LoM Launcher.exe`.

SHA-256 публикуется отдельным файлом рядом с архивом.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
