# LoM Launcher v0.1.5

Небольшой релиз, завершающий локальный гардероб плащей и одновременно проверяющий штатное встроенное обновление с v0.1.4.

## Что изменилось

- В компактном профиле игрока появился отдельный вход в «Гардероб плащей».
- Можно добавлять локальные PNG-плащи, переименовывать, выбирать активный плащ для конкретного аккаунта/профиля и удалять их.
- Выбранный плащ перед запуском клиента экспортируется в `.lom/player/cape.png`.
- В `.lom/player/profile.json` записывается `capeSha256`, поэтому LoM Skin Loader получает плащ через тот же runtime-профиль, что и локальный скин.
- При снятии плаща runtime-файл и `capeSha256` очищаются, чтобы старый плащ не оставался у другого профиля.
- Релиз помечен как совместимый со встроенным ASAR-обновлением (`inAppUpdate: true`).

## Обновление с v0.1.4

LoM Launcher v0.1.4 уже содержит новый механизм обновления. Версия v0.1.5 должна обнаруживаться через «Настройки → Обновление» и устанавливаться как versioned `app.asar` после проверки SHA-256.

Полный ZIP остаётся fallback-вариантом.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-v0.1.5-windows-x64.zip`;
- `LoM-Launcher-v0.1.5-windows-x64.zip.sha256`;
- `app-0.1.5-win.asar`;
- `app-0.1.5-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
