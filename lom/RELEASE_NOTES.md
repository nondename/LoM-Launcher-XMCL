# LoM Launcher v0.1.7

Релиз с исправлениями обновления и гардероба, отдельным установщиком и разделением каналов обновления.

## Что исправлено

- Скины и плащи больше не затирают общий `profile.json` друг друга. Раньше установка плаща могла стереть данные скина и наоборот — теперь операции объединяются, а не перезаписывают файл целиком.
- Встроенное обновление проверяет скачанный ASAR побайтово по SHA-256 до подмены, сохраняет текущую версию как резервную копию и откатывается назад, если подмена не удалась. Лог пишется в `AutoUpdate.log`.
- Обновление больше не требует прав администратора: лаунчер устанавливается в `%LOCALAPPDATA%`, поэтому запрос UAC убран.
- Пункт «отсутствует Java» в меню запуска по клику устанавливает недостающую Java, а не просто показывает подсказку.

## Установщик

Добавлен NSIS-установщик `LoM-Launcher-Setup-0.1.7-x64.exe`:

- ставит лаунчер для текущего пользователя, без запроса прав администратора;
- каталог установки можно выбрать;
- при удалении пользовательские данные не стираются.

Портативная ZIP-сборка сохранена — можно по-прежнему распаковать в любое место.

## Каналы обновления

- Обновления разделены на два канала: основной (stable) и DEV.
- Основной канал получает обычные релизы.
- DEV-канал включается в настройках обновления и получает предрелизы — полезно, чтобы проверить новые версии до широкого выхода.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-Setup-0.1.7-x64.exe`;
- `LoM-Launcher-Setup-0.1.7-x64.exe.sha256`;
- `LoM-Launcher-v0.1.7-windows-x64.zip`;
- `LoM-Launcher-v0.1.7-windows-x64.zip.sha256`;
- `app-0.1.7-win.asar`;
- `app-0.1.7-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
