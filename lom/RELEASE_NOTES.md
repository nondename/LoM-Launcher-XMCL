# LoM Launcher v1.8.10

Стабильное обновление первого запуска и локализации Minecraft.

## Первый запуск

- Возвращён штатный мастер первоначальной настройки на чистой установке.
- На первом экране снова можно выбрать язык лаунчера.
- Язык по умолчанию определяется по системной локали ОС, а не по локали Electron-приложения.
- Например, Windows с локалью `ru-RU` сразу открывает мастер на русском языке.
- Если точная системная локаль не поддерживается, выбирается ближайший поддерживаемый язык или English как fallback.

## Синхронизация языка Minecraft

- Язык лаунчера теперь является источником языка по умолчанию для всех Java-инстансов.
- Перед запуском изменяется только поле `lang:` в `options.txt`; остальные игровые настройки сохраняются.
- Поддерживаются как managed Legends of Medieval, так и обычные пользовательские XMCL-инстансы.
- Для старых версий Minecraft используется исторический формат локали:
  - Minecraft 1.7.10 / 1.10.x: `ru_RU`, `en_US`;
  - Minecraft 1.11+ и 1.20.1: `ru_ru`, `en_us`.
- Учтены файлы `options.txt` с LF и CRLF.

## Проверено

- чистый запуск снова показывает onboarding;
- системная русская локаль выбирает русский язык мастера;
- пользовательский Minecraft 1.7.10 получает `ru_RU`;
- Legends of Medieval 1.20.1 получает `ru_ru`;
- изменение языка не затрагивает остальные строки `options.txt`;
- locale regression tests добавлены в Windows CI и stable release gate;
- Windows production build и NSIS installer проходят CI.

## Загрузка

Для Windows x64 публикуются:

- `LoM-Launcher-Setup-1.8.10-x64.exe`;
- `LoM-Launcher-Setup-1.8.10-x64.exe.sha256`;
- `LoM-Launcher-v1.8.10-windows-x64.zip`;
- `LoM-Launcher-v1.8.10-windows-x64.zip.sha256`;
- `app-1.8.10-win.asar`;
- `app-1.8.10-win.asar.sha256`.

> Windows-сборка пока не подписана Authenticode, поэтому SmartScreen может показать предупреждение при первом запуске.
